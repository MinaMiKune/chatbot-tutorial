🚀 项目简介

这两个工具就像是一对配合默契的搭档：NapCatQQ 负责"操控 QQ"，AstrBot 负责"思考和回复"。

🐱 NapCatQQ 是什么？

NapCatQQ（猫猫框架）是一个基于 QQ 的 Bot 框架。它通过技术手段获取了 QQ 的发送/接收消息接口，让你可以用程序控制 QQ 账号。

✨ AstrBot 是什么？

AstrBot 是一个开源的一站式 Agentic 个人和群聊助手。可以连接到 QQ、飞书、钉钉等 18+ 平台，通过 AI 模型实现智能对话。🚀

📥 安装 NapCatQQ

📋 前置要求：确保已安装 QQ（版本尽量最新，推荐 QQ 9.x）~ 别忘了先更新 QQ 哦！🔔

方法一：Windows 一键版（推荐）

💡 小技巧：一键版就是点点点，3分钟搞定！懒人福音~ 🙌
1

下载 NapCat

前往 GitHub Releases：github.com/NapNeko/NapCatQQ/releases
下载 NapCat.Shell.Windows.Framework.zip（有头绿色版本）

2

解压并运行

解压到一个没有中文和空格的目录（路径干净很重要！），点击 NapCatInstaller.exe 等待自动配置完成

3

启动 NapCat

进入 NapCat.XXXX.Framework 目录，双击运行 NapCatWinBootMain.exe

4

扫码登录

启动后自动打开 WebUI 界面（默认 http://127.0.0.1:6099），用手机 QQ 扫码登录机器人账号

🎉 安装成功！ 登录后可在 NapCat WebUI 中配置 OneBot 服务，成就感满满！

方法二：Shell 手动版 🛠️

1

下载 NapCat.Shell.zip 📦

从 Releases 页面 下载并解压

2

运行启动器

双击 launcher.bat（Win11）或 launcher-win10.bat（Win10）

3

扫码登录

扫码登录后等待 NapCat 启动完成

🐧 Linux 安装

💡 小提示：Linux 用户可以用一行命令搞定，妈妈再也不用担心我装不上啦！

# 标准安装（推荐）
curl -o napcat.sh https://nclatest.znin.net/NapNeko/NapCat-Installer/main/script/install.sh && bash napcat.sh

# 可视化 TUI 安装
curl -o napcat.sh https://nclatest.znin.net/NapNeko/NapCat-Installer/main/script/install.sh && bash napcat.sh --tui

# Docker 安装

⚙️ 配置 NapCatQQ

🌐 网络类型说明

类型说明适用场景
HTTP 服务端NapCat 作为服务端，接收请求AstrBot 作为客户端推送
WebSocket 服务端NapCat 作为服务端，双工通信AstrBot 作为客户端连接（推荐）
WebSocket 客户端NapCat 作为客户端，主动连接AstrBot 作为服务端监听

通过 WebUI 配置（推荐）

1

打开 WebUI

访问 http://127.0.0.1:6099，在启动日志中可找到 Token

2

扫码登录

点击 QRCode 扫码登录，登录后修改密码

3

配置 WebSocket 客户端

进入「网络配置」→「新建」→「WebSocket 客户端」
URL 填写：ws://127.0.0.1:6199/ws
勾选「保存时启用」

配置 FFmpeg（音视频处理）

说明：自 v4.4.11 起，Windows 和 Mac 已内置 FFmpeg。Linux 用户可能需要手动安装。
1

下载 FFmpeg

从 GitHub 下载 ffmpeg-master-latest-win64-gpl.zip

2

解压并配置环境变量

解压到 C:\Program Files\ffmpeg，确保 bin 目录在 PATH 中
bin 文件夹必须包含：ffmpeg.exe、ffplay.exe、ffprobe.exe

3

验证

重启电脑后，在终端运行 ffmpeg -version 验证安装

⚡ 安装 AstrBot

🎯 前置要求：Python 3.12 或更高版本（推荐使用 uv 包管理器，超快！⚡）

Windows / macOS / Linux

是的，你没看错，一个命令全搞定！🤯 不管你是用什么系统， AstrBot 都雨露均沾~

安装命令 
# 使用 uv 安装（推荐，速度快）
pip install uv
uv tool install astrbot --python 3.12

# 或使用 pip 安装
pip install astrbot

# 启动 AstrBot
astrbot

Docker 安装

Docker 命令 
# 拉取并运行 AstrBot
docker run -d \
  --name astrbot \
  -p 6185:6185 \
  -p 6199:6199 \
  -v ~/AstrBot/data:/AstrBot/data \
  ghcr.io/astrbots/astrbot:latest
🎉 安装成功！ 访问 http://localhost:6185 打开管理面板，恭喜你又完成一步！

🛡️ 安全注意

⚠️ 重要提醒：QQ Bot 存在一定风控风险，请勿用于发送违规内容！

账号安全

  • 避免在同一 IP 同时登录 Bot 账号和常用账号
  • 频繁掉线可尝试更换账号或设备
  • 遇到社交风控，解除限制后重新运行即可
  • 可通过设置 NAPCAT_PROXY_ADDRESS 配置代理

平台卸载方式
Windows直接删除 NapCat 目录即可，不影响 QQ
Linux (Docker)删除容器即可，无残留
Linux (本机)重装 QQ 即可完成卸载

❓ 常见问题

🔑 NapCat 登录失败怎么办？

确保 QQ 版本最新，尝试重新扫码。如果持续失败，使用「Windows 一键版本」。也可以尝试以管理员身份运行。重启大法好！🙌

🔌 WebSocket 连接失败？

检查：1) 端口是否被占用；2) 两边 Token 是否一致；3) 防火墙是否阻止；4) AstrBot 是否已启动
💡 提示：大部分连接问题都是 Token 不匹配造成的！

🤖 AI 模型不响应？

检查：1) API Key 是否正确；2) API Base URL 是否正确；3) 账户余额是否充足；4) 查看 AstrBot 日志错误信息
💡 提示：先确认 API 有余额，很多"不响应"其实是钱包空空~

🔐 忘记 WebUI 密码？

修改 data/cmd_config.json 中 dashboard 的 password 键值删除，然后重启。找回密码 so easy~ ✨

如何更新？

NapCat：下载新版本覆盖。AstrBot（uv）：uv tool upgrade astrbot --python 3.12

管理面板显示 404？

下载 dist.zip，解压到 AstrBot/data 目录
